# STEP 0 — 개념 지도 (설치 대기 중에)

실습 전에 이 그림이 머리에 있어야 한다.

```
USD (씬 기술 포맷)
 └── Prim (씬의 모든 노드)
      ├── Xform          좌표 변환
      ├── Mesh           형상
      └── API (스키마)    ← 프림에 "능력"을 덧붙이는 방식
           ├── RigidBodyAPI      이 프림은 물리적으로 움직인다
           ├── CollisionAPI      이 프림은 충돌한다
           ├── MassAPI           질량·관성
           ├── ArticulationRootAPI  이 아래는 하나의 관절체다
           └── DriveAPI          이 관절은 제어기를 갖는다
```

**핵심 개념 — USD는 "API를 붙인다(Apply)"는 방식으로 능력을 추가한다.**
정적인 메시에 `RigidBodyAPI` + `CollisionAPI` + `MassAPI` 를 붙이면 물리 객체가 되고,
관절을 만들고 `DriveAPI` 를 붙이면 제어 가능한 로봇이 된다.

> **이게 왜 중요한가** — 엔닷라이트가 하는 일이 정확히 이거다.
> "형상만 있는 CAD" = Mesh만 있는 프림. 거기에 관절과 물리 API를 붙여 Sim-Ready로 만든다.
> 이 구조를 이해하면 회사 기술을 한 문장으로 설명할 수 있다.

# STEP 1 — GUI 첫 실행과 인터페이스

### 직접 할 것
```powershell
$env:OMNI_KIT_ACCEPT_EULA='YES'
D:\ic\env\Scripts\isaacsim.exe
```
(또는 `& 'D:\ic\env\python.exe' -m isaacsim`)

첫 실행은 셰이더 컴파일로 **수 분** 걸린다. 멈춘 게 아니다.

### 익혀야 할 4개 창

| 창 | 역할 | 단축키/위치 |
|---|---|---|
| **Stage** | 씬의 프림 트리. 여기서 선택 | 우측 상단 |
| **Property** | 선택한 프림의 속성·API | 우측 하단 |
| **Viewport** | 3D 뷰 | 중앙 |
| **Timeline / Play** | 물리 시뮬 시작·정지 | 하단 |

> **처음에 반드시 헷갈리는 것** — **Play를 누르기 전에는 물리가 안 돈다.**
> 로봇을 임포트했는데 안 움직인다고 당황하는 지점이 여기다.
> 그리고 **Play 중에 바꾼 값은 Stop하면 되돌아간다.** 영구 변경은 Stop 상태에서 한다.

### 직접 할 것 — 감 잡기
1. `Create > Shape > Cube` 로 큐브 생성
2. Stage에서 큐브 선택 → Property에서 Transform 확인
3. `Create > Physics > Ground Plane`
4. 큐브를 공중으로 올린다 (Transform Z = 2)
5. 큐브 선택 → Property 하단 `+ Add` → `Physics > Rigid Body`
6. **Play**

### 예측하고 확인
- Rigid Body를 붙이기 **전에** Play를 누르면 큐브가 떨어질까?
- Rigid Body만 붙이고 Collider는 안 붙이면 지면을 통과할까?

직접 해봐라. 두 번째 질문이 특히 중요하다.

### 막히면
- Play를 눌러도 아무 일 없음 → Rigid Body API가 안 붙었다
- 큐브가 지면을 뚫고 내려감 → Collider가 없다. `+ Add > Physics > Colliders`
- 큐브가 안 보임 → Viewport에서 `F` 키 (선택한 프림으로 카메라 이동)

# STEP 2 — URDF 임포트

### 사전 질문 (먼저 답해라)

### 직접 할 것
1. `Window > Extensions` → `isaacsim.asset.importer.urdf` 켜져 있는지 확인
2. `File > Import` → 아래 경로를 그대로 붙여넣는다 (실측 확인된 경로)
   ```
   D:\ic\env\Lib\site-packages\isaacsim\exts\isaacsim.asset.importer.urdf\data\urdf\robots\ur10\urdf\ur10.urdf
   ```

> **경로가 바뀌었으면 이걸로 찾는다** (Isaac Sim을 띄우지 않는다)
> ```powershell
> Get-ChildItem D:\ic\env -Recurse -Filter ur10.urdf | Select-Object -ExpandProperty FullName
> ```
>
> ⚠️ `get_extension_path_from_name()` 을 그냥 `python -c` 로 부르면 **안 된다.**
> 그 함수는 Isaac Sim 앱이 떠 있어야 동작해서, 맨 파이썬에서 부르면 Kit 커널을 부팅하려다

> 경로 하나 알려고 앱 전체를 띄울 이유도 없다.

| STEP | 내용 | 완료 |
|---|---|---|
